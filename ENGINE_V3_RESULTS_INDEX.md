## Гипотеза о причине (не подтверждена тестом, но подтверждена кодом и характером чисел)

Расхождение — только в сборке/пересмотре мира, не в ContractNLI-прогоне. Разница между ними:
сборка/пересмотр считают токены **по блокам**, ContractNLI — **одним чтением итогового
счётчика** в конце.

Подсчёт по блокам сделан в [`dialectic_world/builder/blocks.py:127-129`](dialectic_world/builder/blocks.py):

```python
before = (ctx.llm.usage.prompt_tokens, ctx.llm.usage.completion_tokens)
text = await ctx.llm.generate(messages)
tokens = (ctx.llm.usage.prompt_tokens - before[0], ctx.llm.usage.completion_tokens - before[1])
```

`ctx.llm.usage` — один общий счётчик на все блоки. Когда несколько блоков выполняются
параллельно (`Internals`, по тексту отчёта — «суммарно, параллельно»), между чтением `before`
в одной задаче и вычислением разницы после `await` в неё успевают попасть токены соседних
параллельных вызовов, которые завершились в этом промежутке — гонка на разделяемом счётчике
без блокировки. Это **завышает** сумму по блокам (не занижает) — что и наблюдается (533к > 281к).

Косвенное подтверждение по самим числам: последовательности `tokens` для параллельных вызовов
`Internals` в `build.jsonl` растут монотонно внутри одной параллельной группы, затем резко
падают на границе следующей группы (например: `1940, 1052, 1983, 2230, 1862, 1940` → `1515,
3524, 5423, 7568, 9929` → сброс) — характерный след гонки на общем счётчике, а не независимых
замеров.

`eval_v3.py` не вычисляет разницу по блокам — читает `llm.usage.total` один раз после всех
повторов, поэтому гонка на него не действует. Это согласуется с тем, что там расхождения нет.

**Итого: не общий баг всего пайплайна v3** (вторая независимая таблица ChartractNLI не
затронута), а конкретный, локализуемый по коду источник — конкурентная запись/чтение общего
счётчика токенов в `ask()` при параллельном выполнении блоков. Гипотеза объясняет: (а) почему
расхождение есть только там, где блоки выполняются параллельно, (б) почему оно завышает, а не
занижает итог, (в) почему коэффициент непостоянный (зависит от того, сколько задач оказались
параллельны в какой момент). Не проверялась прямым воспроизведением/тестом на гонку — это
осталось предположением, хоть и хорошо обоснованным.
