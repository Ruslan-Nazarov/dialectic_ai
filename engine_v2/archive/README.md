# Архив v2

Ничто здесь не поддерживается и не будет исправляться. Оставлено целиком ради
воспроизводимости чисел, на которые ссылаются `../../ENGINE_V2_LESSONS.md`,
`../../ENGINE_V3_RESULTS.md` и `../../RESEARCH_HISTORY_AND_PROGRAM.md`.

- **`run_logs/`** — 121 файл сырых логов и результатов прогонов версии 2 (были
  закоммичены прямо в корень `engine_v2/`, вперемешку с кодом пакета). Рядом —
  [`run_logs/INDEX.md`](run_logs/INDEX.md): для каждой цифры из отчётов — точный
  файл-источник, включая проверку, что именно случилось с незавершёнными прогонами.
- **`docs/`** — рабочие документы времени разработки (планы рефакторинга, ревью
  кода, промпт постановки задачи, отчёт о верификации на 2026-09-19). Историческая
  ценность — показывают, как менялось понимание задачи; текущей архитектуры не
  описывают. Для актуального контракта смотри `../RUNTIME_CONTRACT.md`.
- **`dashboard/`** — отдельное React/Vite-приложение для наблюдения за прогонами.
  Не используется ни одним текущим пайплайном (эксперименты запускались и
  разбирались через `.jsonl`-логи и pytest, не через дашборд). Работоспособность
  после переноса не проверялась.
- **`reproduce_gigachat_error.py`** — одноразовый скрипт для репродукции конкретного
  бага; импортирует `dialectic_ai.core.agent.Agent`, которого в текущем коде уже нет
  (модуль удалён при рефакторинге) — скрипт не запустится как есть.
