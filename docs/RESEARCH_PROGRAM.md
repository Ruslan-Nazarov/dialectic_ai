# Research question and next tests

The broader question is where generation should be complemented by independently justified evidence, practice, or human judgement. “AI cannot handle contradictions” remains a hypothesis, not a finding.

The recorded progression is mixed: mandatory dialectical fields did not improve BFCL; early orchestration helped retry handling but harmed another scenario; practice-loop traces showed recovery and honest unresolved reporting alongside failures and high costs; historical domain briefs did not improve ContractNLI; compatibility did not detect correctness; a separate verifier obtained a modest signal, while Jev's own confidence also had signal. The six-prompt rewrite changes the implementation and needs a new efficacy test.

This is an iterative history, not a claim that all changes followed a preplanned theory. See the [historical log](../RESEARCH_HISTORY_AND_PROGRAM.md) and [results](RESULTS.md).

## Next controlled comparison (proposal, not a result)

Preregister a held-out sample before live calls. Compare no context, an equal-length ordinary brief, an equal-budget structured note, and the current engine world. Repeat independent world builds; record language, length, information content, model snapshot and prompt hashes. Separate solver accuracy from error ranking, false alarms, unresolved reports, tool exposure and cost.

For corrupted-tool experiments, require actual exposure before calling a run resistant; include output-format variations and equal-compute engineered verification. For semantic quality, publish a human rubric and blind independent ratings. Verify any post-hoc inverted compatibility score on new data.

Misconceptions and world-vs-plain-text plans remain separate preregistrations. Their amendments and exploratory pilots do not establish comparative benefits of the engine.

## Description for an external researcher

I am investigating where AI reasoning should end and external human or grounded judgment should begin. DialecticAI explores externally imposed reasoning structures, generated domain representations, and verification procedures for existing language models. Generated domain briefs have not produced a detectable ContractNLI accuracy gain, and compatibility self-reports failed to distinguish correct from incorrect answers. A separately invoked verifier showed modest discrimination of saved answers; Jev's confidence on its own answers was also informative. Small synthetic experiments with an earlier practice-loop demonstrated recovery from specific corrupted outputs and explicit unresolved outcomes, with substantial harness and sample-size limitations. The current six-stage builder has software and smoke-test coverage but no established comparative efficacy.
